# Zed Editor + Vim Keybindings Гайд

Это полное руководство по работе с Vim в Zed Editor на основе твоего конфига.

## 📍 Навигация между панелями

### Быстрое переключение между редактором и панелями

| Комбинация | Действие |
|-----------|----------|
| `Ctrl-H` | Перейти на левую панель (Project Panel) |
| `Ctrl-L` | Перейти на правую панель |
| `Ctrl-K` | Перейти на верхнюю панель |
| `Ctrl-J` | Перейти на нижнюю панель |
| `Ctrl-\` | Открыть/закрыть терминал |

### Работа с Project Panel (панель файлов)

| Комбинация | Действие |
|-----------|----------|
| `Space E` | Открыть/закрыть Project Panel |
| `Q` | Закрыть Project Panel |
| `Space Space` | Быстрый поиск файла (File Finder) |

### Действия в Project Panel

Когда фокус на панели файлов:

| Комбинация | Действие |
|-----------|----------|
| `A` | Создать новый файл |
| `Shift-A` | Создать новую папку |
| `R` | Переименовать файл/папку |
| `D` | Удалить файл/папку |
| `X` | Вырезать |
| `C` | Копировать |
| `P` | Вставить |

## ✏️ Редактирование текста

### Режимы в Vim

| Режим | Как войти | Как выйти |
|------|----------|----------|
| **Normal** | Нажми `jj` или `jk` | - |
| **Insert** | Нажми `i`, `a`, `o`, `O`, `I`, `A` | `jj` или `jk` |
| **Visual** | Нажми `v` | `jj`, `jk` или `Esc` |
| **Visual Line** | Нажми `V` | `jj`, `jk` или `Esc` |
| **Visual Block** | Нажми `Ctrl-V` | `jj`, `jk` или `Esc` |

### Вставка текста

| Комбинация | Действие |
|-----------|----------|
| `i` | Вставить перед курсором (Insert mode) |
| `a` | Вставить после курсора (Append) |
| `I` | Вставить в начало строки |
| `A` | Вставить в конец строки |
| `o` | Создать новую строку ниже и войти в Insert mode |
| `O` | Создать новую строку выше и войти в Insert mode |

### Выделение текста

| Комбинация | Действие |
|-----------|----------|
| `v` | Включить Visual mode (посимвольное выделение) |
| `V` | Включить Visual Line mode (выделение строк) |
| `Ctrl-V` | Включить Visual Block mode (блочное выделение) |
| `w` | Выделить слово (с позиции курсора) |
| `iw` | Выделить целое слово (независимо от позиции) |
| `i"` | Выделить содержимое внутри двойных кавычек |
| `i'` | Выделить содержимое внутри одинарных кавычек |
| `i(` или `ib` | Выделить содержимое внутри круглых скобок |
| `i{` или `iB` | Выделить содержимое внутри фигурных скобок |
| `i[` | Выделить содержимое внутри квадратных скобок |
| `$` | Выделить до конца строки |
| `^` | Выделить до начала строки |
| `gg` | Выделить от начала файла |
| `G` | Выделить до конца файла |

### Удаление и копирование

| Комбинация | Действие |
|-----------|----------|
| `d` | Удалить выделенное (в Visual mode) |
| `dd` | Удалить целую строку |
| `dw` | Удалить слово |
| `d$` | Удалить до конца строки |
| `d^` | Удалить до начала строки |
| `x` | Удалить символ под курсором |
| `5dd` | Удалить 5 строк |
| `daw` | Удалить слово вместе с пробелом |

### Копирование (Yank)

| Комбинация | Действие |
|-----------|----------|
| `y` | Копировать выделенное (в Visual mode) |
| `yy` | Копировать целую строку |
| `yw` | Копировать слово |
| `y$` | Копировать до конца строки |
| `yip` | Копировать целый параграф |

### Вставка

| Комбинация | Действие |
|-----------|----------|
| `p` | Вставить после курсора |
| `P` | Вставить перед курсором |

### Изменение текста (Change)

| Комбинация | Действие |
|-----------|----------|
| `c` | Удалить и войти в Insert mode (в Visual mode) |
| `cw` | Заменить слово |
| `cc` | Заменить целую строку |
| `c$` | Заменить до конца строки |
| `ciw` | Изменить целое слово |
| `ci"` | Изменить содержимое внутри кавычек |
| `ci{` | Изменить содержимое внутри фигурных скобок |
| `r` | Заменить один символ |
| `R` | Режим Replace (перезапись нескольких символов) |

### Копирование в/из системного буфера обмена

На macOS (если нужно интегрировать с системным буфером):

| Комбинация | Действие |
|-----------|----------|
| `Cmd-C` | Копировать в систему |
| `Cmd-V` | Вставить из системы |
| `Cmd-X` | Вырезать в систему |

## ➕ Спейсинг между строками

Добавление пустых строк:

| Комбинация | Действие |
|-----------|----------|
| `o` | Создать новую строку ниже и войти в Insert mode |
| `O` | Создать новую строку выше и войти в Insert mode |
| `5o` + `jj` | Добавить 5 пустых строк ниже |
| `3O` + `jj` | Добавить 3 пустые строки выше |

**Workflow:**
1. Находишься в Normal mode
2. Нажимаешь `O` или `o`
3. Появляется новая строка
4. Нажимаешь `jj` для выхода в Normal mode (без добавления текста)

## 🚀 Практические примеры

### Пример 1: Найти и заменить слово

```
1. Space /          → Открыть проектный поиск
2. Введи слово
3. Enter            → Перейти к первому результату
4. ciw              → Выбрать слово и войти в режим замены
5. Введи новое слово
6. jj               → Выход в Normal mode
```

### Пример 2: Удалить функцию

```
1. Space /          → Найти имя функции
2. GD               → Перейти к определению
3. V                → Visual Line mode
4. Ctrl-L           → Выделить до конца (или G для конца файла)
5. d                → Удалить
```

### Пример 3: Копировать блок кода в AI

```
1. v                → Visual mode
2. Выдели блок кода (стрелки или hjkl)
3. y                → Копировать (Vim буфер)
4. Space AC         → Открыть AI Assistant
5. Cmd-V            → Вставить в чат
```

### Пример 4: Переименовать переменную

```
1. Наведи курсор на переменную
2. Space CR         → Rename (рефакторинг)
3. Введи новое имя
4. Enter            → Применить ко всем использованиям
```

### Пример 5: Быстро открыть файл

```
1. Space Space      → File Finder
2. Начни печатать имя файла (например: "order")
3. Enter            → Открыть найденный файл
```

## 💡 Советы и трюки

### Быстрая навигация
- **Используй `Space Space` вместо щелчков** по файлам — это намного быстрее
- **Ctrl-H/L/K/J** — основной способ переходить между панелями, не трогай мышь

### Эффективное редактирование
- **Комбинируй операторы**: `d3w` = удалить 3 слова, `5dd` = удалить 5 строк
- **Используй текстовые объекты**: `ciw`, `di"`, `da{` — удобнее, чем ручное выделение
- **Запомни буквы**: `i` = inner (внутри), `a` = around (вместе с разделителем)

### Спасение времени
- `gg` + `G` = выделить всё
- `.` = повторить последнюю команду
- `u` = undo (отменить)
- `Ctrl-R` = redo (повторить)

### Буфер обмена
- Vim использует собственный буфер (`y`/`p`)
- Система использует `Cmd-C`/`Cmd-V` (на Mac)
- Для кроссплатформенного копирования используй системные команды

## 🔧 Если что-то не работает

1. **Проверь режим**: Нажми `Esc` несколько раз, потом `i` или `v`
2. **Перезагрузи Zed**: Cmd-Q и открой заново
3. **Проверь конфиг**: Смотри `~/.config/zed/keymap.json`
4. **Используй Command Palette**: Cmd-Shift-P и введи название команды

## 📚 Быстрая справка по режимам

```
Normal Mode (стандартный режим)
├─ Навигация: h, j, k, l, w, b, G, gg
├─ Удаление: d, dd, dw, x
├─ Копирование: y, yy, yw
├─ Вставка: p, P
├─ Замена: c, r, R
└─ Выделение: v, V, Ctrl-V

Insert Mode (редактирование текста)
├─ Любые символы вводятся как текст
└─ jj/jk = выход в Normal Mode

Visual Mode (выделение)
├─ Выбираешь текст
└─ d/c/y для операций над выделением
```
